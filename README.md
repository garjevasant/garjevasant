I'm **Vasant Garje**, an Indian Army veteran and hands-on, multidisciplinary developer based in **Pune, Maharashtra, India**. My background combines technical systems, communications, IT and finance with practical software engineering.

I enjoy building **complete, usable solutions**—from frontend interfaces and backend APIs to mobile apps, databases, computer vision, radio-frequency tools, and deployment workflows. I work across multiple languages, frameworks and platforms, selecting the right technology for each problem.

- 📱 **Mobile engineering:** Android/Kotlin, Jetpack Compose and Flutter/Dart
- 🛡️ **Security-minded development:** app hardening, networking, privacy and offline-first design
- ☁️ **Systems & infrastructure:** Linux, Windows, Docker, AWS, Nginx and application deployment
- 🎖️ **Service mindset:** discipline, reliability, teamwork and mission-oriented problem solving

- Integrating **HackRF One**, GNU Radio and Android/desktop software.
- Working with **signal detection concepts**, FFT-based analysis and CFAR techniques.
- Exploring **LoRa**, antennas, RF modules and connected embedded systems.
